# Todo App

A simple full-stack Todo app built with vanilla HTML/CSS/JS on the frontend and Node.js + Express on the backend. Todos are stored in memory (no database).

## Features
- Add a new todo
- View all todos
- Mark a todo as complete/incomplete
- Delete a todo
- Empty-state message when there are no todos
- Basic input validation (empty todos are rejected)

## Tech Stack
- Frontend: HTML, CSS, vanilla JavaScript (fetch API)
- Backend: Node.js, Express
- Storage: in-memory array
## Status
Core CRUD complete: add, list, toggle-complete, delete.
